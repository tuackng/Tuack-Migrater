# Tuack Migrater

这是从 Tuack V2 配置文件版本迁移到 V7 版本的工具。

## 使用

安装本包，并调用 `python3 -m tuack-migrater <你希望迁移后的新工程目录>`。

在迁移过程中，您可能需要回答一些问题，并且需要在迁移后对部分内容进行手动适配，本工具会做出提醒。

整个过程不会对原有工程产生任何影响，您可以放心执行。

详见 <https://docs.tuack-ng.ink/app/special/migrate-tuack/overview.html>。
